# Superformula Reverb v1.0.0

The first public release of CVA Labs Superformula Reverb.

The VST3 combines an interactive 3D Gielis superformula room with a geometry-driven feedback delay network. Shape, scale, decay, pre-delay, dry/wet balance, and eight Bayin material voices can be automated and recalled by the host.

## Downloads

- **Windows x64:** `Superformula-Reverb-Windows-x64.zip`
- **macOS Universal:** `Superformula-Reverb-macOS-Universal.zip` for Apple Silicon and Intel Macs

The macOS build is unsigned and not notarized. Installation and first-launch instructions are included in the README.
